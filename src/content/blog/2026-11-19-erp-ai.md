張志恒的行業観察の日報（2026-11-19）から、ERP×AI の注目ニュースをまとめます。頭条は Microsoft Ignite 2026 です。

## Microsoft Ignite 2026：Copilot Workspaces と Dynamics 365 in Copilot

複数人で協働できるエージェント画面「Copilot Workspaces」、自律的に業務を進める Autopilot エージェント、Agent 365 のコスト管理（ROI 追跡）が発表されました。Dynamics 365 を Copilot 内で使う機能も出ています。

**日本企業にとっての意味：**ERP 操作がチャットとエージェント経由に移りつつあります。導入時は効果測定とコスト管理の仕組みを最初から決めておくと運用しやすくなります。

## Microsoft「Licensed Weights」：自社データでモデルをカスタマイズ

自社データで最先端モデルをカスタマイズし、Azure 上で安全に動かせるプログラムです。ナデラ CEO は MAI Code 2 と MAI Image 2.7 も発表し、MAI Code 2 は低コストで GPT 6.1 Sol や Claude Opus 5.5 に近い性能と紹介されています（自社発表ベース）。

**日本企業にとっての意味：**機密性の高い基幹データを扱う企業にとって、データを外に出さず調整できる選択肢は魅力です。性能は第三者検証を待って判断したいところです。

## Databricks が第2世代 Genie を発表、欧州に30億ドル投資

自然言語クエリから、Genie One・Genie Code・Genie Agents などへ拡張し、意味層「Genie Ontology」が正式提供になりました。今後3年で欧州・中東に30億ドルを投じる方針も示されています。

**日本企業にとっての意味：**ERP データを分析基盤に集める企業では、意味層の整備が AI 活用の精度を左右します。用語定義の整理は今から始められます。

## Workday が Honeydew の買収意向を発表

AI と BI 向けの意味層を提供する Honeydew を買収する意向を発表しました。詳細条件は日報では触れられていません。

**日本企業にとっての意味：**HCM・財務の SaaS ベンダーが意味層を取り込む動きは、ERP 各社が「AI が正しくデータを理解する基盤」を競争軸にしている表れです。

## SAP が Gartner の人材獲得スイート部門で顧客の選択に

293 件の検証済みレビューに基づく評価で、SAP は人材獲得スイートの Customer's Choice に選ばれました。SuccessFactors の AI 機能も SAP Connect で紹介されています。

**日本企業にとっての意味：**HCM 製品を検討する際、第三者の利用者評価は比較材料になります。AI 機能の実利用レビューも併せて確認すると良いでしょう。
